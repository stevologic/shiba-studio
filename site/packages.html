Packages

Official Windows and iOS apps. CI compiles both on every push to main and development, then publishes the artifacts here.

Shiba Studio for Windows

Native WebView2 host. Start a local checkout with npm run start, or attach to a Studio that is already running on this machine.

Artifact: ShibaStudio-windows-x64.zip

Download stable (main) Download development

Stable channel updates on every push to main.

Development channel updates on every push to development.

Shiba Studio for iOS

Official companion. Pair it with a Studio host that has remote Companion access enabled — the full Node server cannot run on iPhone or iPad.

Artifact: ShibaStudio-ios-simulator.zip

Download stable (main) Download development

Stable channel updates on every push to main.

Development channel updates on every push to development.

The iOS zip is a simulator build produced by xcodebuild on every push. Device and App Store signing stay a human Apple-certificate step; the Xcode project lives in apps/ios. Windows needs the Evergreen WebView2 runtime (already present on current Windows 11).
